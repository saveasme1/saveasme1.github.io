Windows / Mac

Chrome 또는 Edge에서 이 PC에 앱으로 설치합니다. Safari(맥)는 PC 설치를 지원하지 않습니다.

  1. 아래 버튼을 누르거나
  2. 주소창 오른쪽 설치(⊕) / 메뉴 → 앱 설치
설치 준비 중…
사이트로 바로 열기
🤖

Android

Chrome · 삼성 인터넷에서 홈 화면에 추가하거나 앱으로 설치합니다.

  1. 휴대폰 Chrome으로 이 페이지를 엽니다
  2. 메뉴(⋮) → 앱 설치 / 홈 화면에 추가
휴대폰에 붙여넣어 여세요


iPhone

카메라로 QR을 찍으면 Safari로 열립니다. 공유 → 홈 화면에 추가.

  1. 기본 카메라로 QR 스캔
  2. Safari에서 공유 → 홈 화면에 추가

아이폰 설치

  1. 아이폰 기본 카메라로 QR을 찍습니다.
  2. 알림을 눌러 Safari로 엽니다.
  3. 하단 공유 → 홈 화면에 추가

카톡 안에서는 설치가 안 됩니다. Safari로 연 뒤 추가하세요.

Android 설치

  1. Chrome 또는 삼성 인터넷으로 이 페이지를 엽니다.
  2. 앱 설치하기를 누르거나
  3. 메뉴(⋮) → 앱 설치 / 홈 화면에 추가

카톡 안이면 먼저 “브라우저에서 열기”로 Chrome을 여세요.
