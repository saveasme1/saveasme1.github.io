Android

1단계 · 추천 설치 링크 복사 → 휴대폰 브라우저에서 연 뒤 → 앱 설치하기 버튼을 누르면 됩니다.

복사한 주소를 휴대폰 Chrome·삼성 인터넷에 붙여넣어 여세요

2단계 · 자동 설치가 안 될 때 다시 설치 링크 복사 후 휴대폰에서 열고, 아래 메뉴대로 현재 페이지 추가 → 홈 화면을 선택하세요.

앱이 자동으로 설치되지 않을 때 아래 설치 링크 복사 후, 그림 안내대로 현재 페이지 추가 → 홈 화면을 선택하세요.

Chrome이라면 메뉴(⋮)에 홈 화면에 추가 또는 앱 설치가 보일 수 있습니다. ‘앱 설치’ 시 Play 프로텍트 경고가 뜨면 무시하고 설치하기를 누르면 됩니다.

메뉴가 정상적으로 보이지 않으면 카카오톡 등 앱이 아니라 브라우저에서 열기로 연 뒤 다시 시도하세요.

iPhone

1단계 · PC에서 아이폰 기본 카메라로 QR을 스캔하거나, 아래 링크를 복사해 아이폰 Safari에 붙여넣어 열어 주세요.

QR이 가장 빠르고, 안 되면 링크를 Safari에 붙여넣기

2단계 · 아이폰 Safari에서 하단 공유 → 홈 화면에 추가를 선택하면 설치가 끝납니다.

Safari에서 추가 순서

  1. 알림을 눌러 Safari로 엽니다 (카톡 안이면 Safari로 전환)
  2. 하단 공유 → 홈 화면에 추가 → 추가

공유·추가가 정상적으로 보이지 않으면 카카오톡 등이 아니라 Safari에서 다시 열어 주세요.

지금 아이폰에서 이미 이 페이지를 보고 있다면 QR·복사가 필요 없습니다. Safari에서 공유 → 홈 화면에 추가만 하면 됩니다.

Safari로 보고 있다면

  1. 하단 공유 버튼을 누릅니다
  2. 홈 화면에 추가 → 추가

카카오톡 등 앱 안에서 열렸다면

  1. 위 Safari에서 열기로 먼저 이동합니다
  2. Safari에서 공유 → 홈 화면에 추가

공유 메뉴가 안 보이거나 설치가 안 되면 앱 안이 아니라 Safari에서 열기로 연 뒤 다시 시도하세요.
