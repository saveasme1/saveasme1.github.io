컴퓨터

Windows와 Mac에서 같은 설치 버튼을 씁니다. 다만 브라우저가 중요합니다.

설치 가능: Windows / Mac의 Google Chrome 또는 Microsoft Edge. 설치 후 시작 메뉴(Windows) · Dock/런치패드(Mac)에서 앱처럼 실행됩니다.

Mac Safari는 이 버튼으로 설치되지 않습니다. Safari는 Chrome/Edge와 같은 ‘앱 설치’ 기능을 지원하지 않습니다. Mac에서는 Chrome 또는 Edge로 이 페이지를 연 뒤 위 버튼을 눌러 주세요.

  1. Chrome 또는 Edge로 이 페이지를 엽니다 (Safari X)
  2. 위 PC에 앱 설치를 누르거나
  3. 주소창 오른쪽 설치 아이콘 · 메뉴의 앱 설치를 선택하세요
