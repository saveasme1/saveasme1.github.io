헤리티지 앱 설치

컴퓨터

Chrome 또는 Microsoft Edge에서 설치하면 시작 메뉴·독에서 앱처럼 실행됩니다.

  1. 아래 PC에 앱 설치를 누르거나
  2. 주소창 오른쪽 설치 아이콘 · 메뉴의 앱 설치를 선택하세요
잠시만 기다려 주세요
웹으로 바로 이용

Android

스마트폰 Chrome 또는 삼성 인터넷에서 홈 화면에 추가해 앱처럼 사용하세요.

  1. 휴대폰 브라우저로 이 페이지를 엽니다
  2. 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택하세요
복사한 주소를 휴대폰 브라우저에 붙여넣기

iPhone

카메라로 QR을 스캔한 뒤 Safari에서 홈 화면에 추가하세요.

  1. 기본 카메라로 QR을 스캔합니다
  2. Safari에서 공유 → 홈 화면에 추가

아이폰 설치

  1. 아이폰 기본 카메라로 QR을 찍습니다.
  2. 알림을 눌러 Safari로 엽니다.
  3. 하단 공유 → 홈 화면에 추가

카카오톡 등 앱 안에서는 설치할 수 없습니다. Safari로 연 뒤 홈 화면에 추가하세요.

Android 설치

  1. Chrome 또는 삼성 인터넷으로 이 페이지를 엽니다.
  2. 앱 설치하기를 누르거나
  3. 메뉴(⋮) → 앱 설치 / 홈 화면에 추가

카카오톡 등 앱 안이라면 먼저 브라우저에서 열어 주세요.
